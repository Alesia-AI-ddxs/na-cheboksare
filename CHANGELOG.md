# Что нового в «На Чебоксаре»

Первый раздел (под самым верхним заголовком «##») скрипты публикации берут как текст «Что нового» для магазинов,
если не задана переменная RUSTORE_WHATS_NEW. Пишите коротко и только правду.

## 1.1.0

- Выбор языка: при первом запуске приложение предлагает язык телефона; каждый язык написан на самом себе, без флагов.
- Можно заранее выбрать произношение для будущей озвучки (например, британский или ирландский английский, путунхуа или кантонский).
- Новый язык — арабский (черновой перевод, вычитка носителем впереди); интерфейс справа налево.
- Свои шрифты для китайского, хинди и арабского — без «квадратиков» вместо букв.
- «Вы нашли 5 находок» — числа и слова склоняются по правилам каждого языка.
- Язык меняется во вкладке «О проекте» и запоминается. Сетнер узнаёт выбранный язык.
