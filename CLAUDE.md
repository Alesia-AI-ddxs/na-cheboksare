# Правила студии для исполнителей — «На Чебоксаре» (Expo / React Native)

Проект: мобильное приложение-квест «На Чебоксаре», направление «Туризм — Чебоксары», студия Иноспектрум Мобилиус.
Версия приложения: 1.2.0 (волна 0: «Лаборатория замеров» и разъём «вариант Э», рекомендации владельца 23.10.2026; таблица контента v2.9).
Откат на 1.1.1 — ветка `release/1.1.1`, раздел «Откат на 1.1.1» в `README_СТУДИИ.md`. Подробности и команды — там же.

## Главные правила (нарушать нельзя)

1. **Все строки, которые видит пользователь, — только из мастер-таблицы** через генератор: `locales/<код>.json`
   (строки интерфейса, тексты T…, предания L…) и `src/content/content.json` (структура). Показывать — только через
   `t('ключ')` / `tOpt('ключ')` из `useGame()`. В коде НЕТ ни одной фразы интерфейса и нет «запасных» строк
   (аварийных lastResort больше нет). Новый ключ: сначала строка в листе «Интерфейс» (ru-RU обязательно), потом генератор.
2. **Ничего не выдумывать.** Ни исторических фактов, ни дат, ни цитат, ни переводов. Нет текста в JSON — показываем
   метку `ui.soon` («готовится»). Новый текст появляется только через мастер-таблицу контента → `tools/content_build.py`.
3. **Никаких лиц, кроме Олеария.** Единственное изображение человека — подлинная гравюра Адама Олеария (1669,
   общественное достояние): `assets/images/olearius_1669.jpg`, подключена в `src/portraits.ts`.
   Остальные рассказчики — абстрактные значки (`SpeakerIcon`). Не генерировать и не вставлять портреты.
4. **Код не зависит от номеров точек.** Всё (сколько точек, какие этапы, какие находки) берётся из JSON.
   `content.json` должен заменяться целиком без правок кода.
5. **Сборки — через EAS или на своём сервере (`server/build_android.sh`)** и только после зелёного `npm run check`.
6. **Ключи и пароли никогда не кладём в репозиторий** (keystore, токены RuStore/Google, `.env*`, папка `secrets/`).
   Подпись: в облаке — у EAS, на своём сервере — `secrets/*.jks` + `.env.signing` (только у владельца).
7. **Веб-версия = PWA.** `src/app/+html.tsx` обязан выводить `headNodes` и `bodyNodes` (иначе на сайте не работают кнопки).
   Веб-сборка — только `npm run web:export` / `web:export:turizm` (они готовят `sw.js` для работы без интернета и собирают
   с `--clear`: иначе Metro вшивает в сайт устаревший app.json — так в 1.1.1 браузер видел версию «1.0.0»).
8. Приложение **полностью офлайн**: без аналитики, без сетевых запросов, без разрешений. Ссылки (Telegram, сайт)
   открывает система.

## Языковой модуль (правила, нарушать нельзя)

9. **Единица — языковой вариант** (en-GB ≠ en-US; zh-Hans / zh-Hant / yue-Hant — три; mdf и myv — два языка, слово
   «мордовский» в интерфейсе не употреблять; cv — единый). Список вариантов в коде — ТОЛЬКО `src/i18n/languages.ts`
   (зеркало листа «ЯЗЫКИ»). `content.languages` для списка не использовать.
10. **Лестница фолбэка:** точный вариант → старший → en-GB → ru-RU. Пустых строк и «□» не бывает: пустую ячейку не пишем
    в пакет, строку подставит лестница. ru-RU всегда полный (`npm run check` проверяет).
11. **Числа и склонения — ICU** (`{count, plural, one {…} few {…} many {…} other {…}}`), даты и числа — `formatDate` /
    `num()` средствами локали. Не склеивать фразы из кусков в коде.
12. **Без флагов стран.** Язык показывается эндонимом (на самом себе) первой строкой.
13. **Справа налево:** стрелки и значки берём из `dir` (`dir.back`, `dir.fwd`, `dir.expand`), выравнивание «к концу» —
    `dir.end`; не писать `'←'`, `'→'`, `textAlign: 'right'` напрямую. Разрядку букв (`letterSpacing`) — только если `f.spacing`
    (у арабского и деванагари буквы связаны).
14. **Шрифты письменностей** грузятся только для выбранного языка (`src/i18n/fonts.ts`) и с 1.1.1 — только
    **подмножества** `assets/fonts/subset/<Семейство>.ttf` (буквы из строк таблицы + цифры, латиница, знаки; у арабского и
    деванагари — весь блок письма). Их собирает генератор (`tools/content_build.py` → `tools/font_subset.py`), список —
    `src/i18n/fontFiles.ts` (руками не править). Полные Noto из `node_modules` в код НЕ подключать. Письмо без переведённых
    языков (сейчас zh-Hant, yue-Hant) в сборку не входит; появятся тексты — подмножество создастся само. Нужно:
    `pip install fonttools brotli`. `npm run qa:tofu` проверяет строки и тест-строки по подмножеству («потеряно» = ошибка).
15. Офлайн и приватность сохраняются: без адреса `extra.langPackBaseUrl` приложение в сеть не ходит; выбор языка хранится
    только на устройстве. Ключей и паролей в коде нет.
16. **Ссылка на Сетнера** строится ТОЛЬКО в `src/setnerLink.ts`: `https://t.me/<бот>?start=<код>_<письменный>[_<голосовой>]`
    (голос — третьим полем, только если его код отличается от письменного варианта). Telegram передаёт боту только `start`:
    латиница, цифры, `_` и `-`, длина ≤ 64; не помещается — сначала отбрасываем голос, потом язык; код прохождения не теряем.
    Отдельных `&lang=` / `&voice=` нет. Проверка — `npm run qa:setner`.
17. **Страны вариантов:** колонка «Страны (ISO 3166-1)» листа ЯЗЫКИ = поле `regions` в `src/i18n/languages.ts`
    (`npm run check` сверяет). Страну берём только из настроек телефона (`expo-localization` → `regionCode`) — без геолокации,
    без сети, без разрешений. Блок «Предлагаем» — язык телефона + варианты страны, только переведённые («готовится» — нет).
18. **Имена — по листу ИМЕНА** (название игры, Чебоксары, Волга, Сетнер, Чувашия, залив). `ui.title` = название из ИМЕНА
    прописными. Транслит «Na Cheboksare» и чужие написания запрещены — `npm run qa:names` (`tools/names_check.py`).

## Волна 0 (v1.2.0, правила, нарушать нельзя)

19. **«Лаборатория замеров»** (`src/app/lab.tsx`, `src/lab/`) — скрытый служебный экран для владельца и тестировщиков.
    Вход только 7 касаниями подряд по строке версии содержания во вкладке «О проекте» и ссылкой `nacheboksare://lab`;
    в меню, на других экранах, в магазинах и в «Что нового» её НЕ упоминаем. Без сети, без разрешений, без сохранения:
    отчёт живёт только на экране (скопировать / поделиться), в отчёте только модель и цифры (без имени устройства и кода
    прохождения). Подписи — только ключи `lab.*` таблицы. Пороги итога — ТОЛЬКО `src/lab/thresholds.ts` (из документа
    владельца 23.10.2026: ≥30 к/с); ступени и длительность — `src/lab/config.ts`. Проверка — `npm run qa:lab`.
20. **Разъём «вариант Э»** (отдельное 3D-приложение по ссылке): ссылка строится ТОЛЬКО в `src/unity/appLink.ts` —
    `<схема>://scene/<номер точки>?lang=<письменный вариант>&code=<код>`; схема и адрес магазина — ТОЛЬКО из `app.json`
    (`extra.unity3dScheme`, `extra.unity3dStoreUrl`), в коде их нет. Пустая схема — кнопки «Открыть в 3D» нет вовсе
    (в браузере — никогда). Запись `<queries>` / `LSApplicationQueriesSchemes` добавляет только плагин
    `plugins/with-unity-3d-queries.js` и только при непустой схеме; после смены схемы — новая сборка (не обновление по воздуху).
    Встроенный модуль (`UNITY_ENABLED`) остаётся `false`. `metro.config.js` не даёт expo-gl тянуть в сборку react-native-reanimated.

## Перед сдачей любой правки

```bash
npm run check          # проверка типов + проверка контента и языковых пакетов (ICU, полнота ru-RU, ключи из кода)
npm run qa:plural      # формы чисел 1/2/5/21 (ru-RU и ar сверяются с ожидаемыми)
npm run qa:tofu        # нет ли букв без шрифта (по подмножествам шрифтов)
npm run qa:names       # имена по листу ИМЕНА (нет транслита и чужих написаний)
npm run qa:setner      # формат ссылки на Сетнера (start=<код>_<язык>[_<голос>], ≤ 64)
npm run qa:lab         # лаборатория: итог зелёный/жёлтый/красный, кадры/с, отчёт, ссылка «вариант Э»
npm run web:export     # веб-сборка (PWA) в dist/ (и web:export:turizm — для /turizm/app/)
npm run pwa:check      # PWA: установка и работа без интернета
npm run qa:screens     # снимки экранов в qa/screens/
npm run test:publish   # если трогали скрипты публикации
```

## Где что лежит

- `src/app/` — экраны (Expo Router): `prologue`, вкладки `(tabs)/route|finds|setner|about`, `point/[id]`, `finish/[stage]`.
- `src/content/` — `content.json` (источник правды) и типы.
- `src/i18n/` — языковой модуль: `languages.ts` (реестр), `index.ts` (i18next + ICU, выбор/сохранение языка, RTL),
  `fonts.ts` (шрифты письменностей), `audio.ts` (разъём озвучки); экран выбора — `src/screens/LanguageSelectScreen.tsx`.
- `locales/` — пакеты строк по языкам (генерируются из таблицы, руками не править).
- `src/state/game.tsx` — прогресс игры (AsyncStorage, только на устройстве).
- `src/components/` — виньетки сцен, карта маршрута, иконки, кнопки.
- `src/unity/` — слот под встроенный Unity (выключен) и «вариант Э»: `config.ts`, `appLink.ts`, `Open3DButton.tsx`.
- `src/app/lab.tsx`, `src/lab/` — «Лаборатория замеров» (пороги — `thresholds.ts`); `plugins/` — плагин `<queries>`;
  `metro.config.js` + `metro-shims/` — без react-native-reanimated в сборке.
- `scripts/` — проверка контента, генератор иконок, QA-снимки.
- `tools/content_build.py` — сборка `content.json`, `locales/*.json` и подмножеств шрифтов из мастер-таблицы;
  `tools/font_subset.py` — подмножества шрифтов; `tools/tofu_check.py` — проверка шрифтов; `tools/names_check.py` — имена;
  `tools/apply_v28.py`, `tools/apply_v29.py` — правки таблицы v2.7 → v2.8 → v2.9 (архив).
- `src/setnerLink.ts` — ссылка на бота Сетнера (единственное место); `assets/fonts/subset/` — подмножества шрифтов.
